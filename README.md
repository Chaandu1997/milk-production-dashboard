# milk-production-dashboard
Milk Production Dashboard built in Excel to analyze village-wise and farmer-wise milk collection. Includes KPIs like Fat %, SNF %, Quantity, Amount, and Price per Liter. Features interactive charts, trends, and filters to monitor performance and identify top contributors.

Milk Production Dashboard

📊 Project Overview

This project analyzes and visualizes milk production data from different villages and farmers. The dashboard provides insights into milk trends, quality parameters, and farmer contributions, helping in better monitoring and decision-making.

🛠 Tools & Techniques

Excel Dashboard (Pivot Tables, Charts, Slicers)

Data cleaning and summarization

Interactive filters for Village, Date, and Farmer

📈 Dashboard Features

Milk Trend: Daily milk collection trends across the month

Village-wise Milk: Comparison of milk collection by village

Top Farmers: Ranking of farmers by quantity supplied

Slicers/Filters: For Village, Date, and Farmer-wise analysis

🚀 How This Helps

Monitors milk production performance

Identifies top-contributing villages and farmers

Helps optimize pricing and quality management
